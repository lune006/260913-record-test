# TASTE NOTE

커피와 디저트의 맛, 향, 장소와 순간을 기록하는 반응형 웹 서비스입니다.

## 주요 기능

- 커피 6종, 디저트 6종의 펜 드로잉 스타일 메뉴 선택
- 향, 단맛, 바디감, 균형을 5단계로 기록
- 10가지 향미 태그와 한 줄 메모, 만족도 저장
- 커피/디저트 기록 필터 및 개별 삭제, 전체 비우기
- 브라우저 `localStorage` 기반 데이터 유지
- 데스크톱, 태블릿, 모바일 반응형 레이아웃

## 디자인

- 메인 컬러: 에스프레소 브라운
- 배경: 웜 오프화이트
- 폰트: Pretendard
- 생성형 펜 드로잉 일러스트와 직접 제작한 라인 아이콘 사용
- 그라데이션 및 이모지 미사용

## 실행

`dist/index.html`을 직접 열거나 프로젝트 루트에서 `python3 -m http.server 4173 --directory dist`를 실행한 뒤 `http://localhost:4173`으로 접속합니다.
